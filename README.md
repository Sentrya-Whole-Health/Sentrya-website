# Sentrya website
a beta testing public facing app for the app Sentrya Whole Health

Jekyll site, published by GitHub Pages from `main` to https://mysentrya.com.
Shared header/footer live in `_includes/`, the page shell in `_layouts/default.html`.

Preview locally: `jekyll serve`, then open http://localhost:4000

See `SITE-NOTES.md` for how the site is structured, the accessibility audit, and open items.
